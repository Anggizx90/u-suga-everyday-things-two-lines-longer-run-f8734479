A program that writes exactly two lines to `/output/entry.txt`: line 1 explains a traffic jam to a 10-year-old in a single vivid sentence built on one analogy, and line 2 says in one sentence what that analogy maps and what it leaves out.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
